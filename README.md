# 崇右 Model Cards — 加密存取版

這個版本只可發布公開的登入介面與 `catalog.enc`。學生名單、測量資料及四張固定照片均保存在加密資料檔內，未登入時不載入可讀取的學生內容。

## 存取方式

使用管理者透過私人方式提供的共用通行碼。PBKDF2-HMAC-SHA256（600,000 次）衍生金鑰，以 AES-256-GCM 及每次重新產生的 salt/IV 加密整份 gzip 資料包。通行碼與解密金鑰不包含在 GitHub 或部署產物中，不保存在 localStorage/sessionStorage。重新整理或登出後必須再次輸入。

共用通行碼不是個人帳號；持有通行碼的人皆能解鎖。更換通行碼需重新加密並發布。已獲准查看的人仍可下載 MDC，登出不會收回其下載的圖片。

## 發布與維護

GitHub Actions 僅發布 `index.html`、`app.js`、`auth.js`、`style.css`、`catalog.enc`。嚴禁加入 `data.json`、`assets/`、原始照片、通行碼檔案或解密後的資料。

原明文資料儲存庫必須設為私人，且舊公開 Pages 必須下線；在完成前，單獨部署此登入介面不足以保護曾經公開的檔案。公開儲存庫應從此加密版本建立乾淨的新歷史，避免歷史版本提供明文旁路。

班級以入學年度與班別分組，MDC 內不顯示班級。裁切 v2 保留來源照片頂部，使用 contain 與留白，避免切掉頭髮；全身與自由 Pose 保留完整原圖。
